# wbuy E-commerce Website

## Project Overview
wbuy is a full-stack e-commerce website built with Django. This platform allows users to browse products, add them to their cart, and complete purchases while providing a secure and efficient shopping experience.

## Features
- **User Authentication**: Users can create accounts, log in, and manage their profiles.
- **Product Catalog**: A dynamic catalog where users can view various products categorized by type.
- **Shopping Cart**: Users can add or remove products, and view their cart before checkout.
- **Order Management**: A complete order management system including order history and status tracking.
- **Admin Panel**: An easy-to-use interface for managing products, orders, and users by site administrators.
- **Responsive Design**: The website is designed to work seamlessly across different devices and screen sizes.

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python, Django
- **Database**: SQLite / PostgreSQL
- **Deployment**: Heroku / AWS
- **Version Control**: Git / GitHub

## How to Set Up Locally
1. Clone the repository:
   ```sh
   git clone https://github.com/Abhinavvel2006/wbuy.git
   cd wbuy
   ```
2. Install the required packages:
   ```sh
   pip install -r requirements.txt
   ```
3. Run the development server:
   ```sh
   python manage.py runserver
   ```
4. Access the site at `http://127.0.0.1:8000/`
